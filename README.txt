วิธีเปิดใช้งานเว็บไซต์
1. แตกไฟล์ ZIP นี้ก่อน
2. เปิดโฟลเดอร์ tiaobanrao_website
3. ดับเบิลคลิกไฟล์ index.html เพื่อเปิดหน้าแรกในเว็บเบราว์เซอร์
4. รูปภาพอยู่ในโฟลเดอร์ images ห้ามย้ายไฟล์รูปออกจากโฟลเดอร์นี้
5. ทุกหน้าเชื่อมโยงกันผ่านเมนูด้านบน

ไฟล์หลัก
- index.html = หน้าแรกและสไลด์ภาพ
- places.html = สถานที่ท่องเที่ยว
- food.html = อาหาร
- plan.html = วางแผนเที่ยว
- travel.html = ข้อมูลการเดินทาง
- login.html = หน้าเข้าสู่ระบบตัวอย่าง
- style.css = ตกแต่งเว็บไซต์
- script.js = ควบคุมสไลด์ภาพและฟอร์มตัวอย่าง

ข้อควรทราบ: หน้าเข้าสู่ระบบยังเป็นแบบสาธิต ไม่ได้เก็บบัญชีหรือรหัสผ่านจริง
